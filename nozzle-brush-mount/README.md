# Nozzle Brush Mount

![Nozzle Brush Mount CAD](../images/nozzle-brush-mount-cad.png)

A two-piece mount that attaches to the 2020 extrusion frame and holds a silicone nozzle brush and a Sexball probe in line with the docking pathway.

**Nozzle brush:** The silicone brush cleans the nozzle automatically every time a tool is docked or undocked, preventing plastic buildup that could otherwise affect print quality on longer prints.

**Sexball probe:** With one button press, each tool head is automatically picked up, its nozzle cleaned, and the probe used to measure the nozzle position from multiple angles. XYZ offsets are then applied automatically across all six tool heads, eliminating the need for manual calibration.
