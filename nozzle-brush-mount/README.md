# Nozzle Brush Mount

![Nozzle Brush Mount CAD](../images/nozzle-brush-mount-cad.png)

A two-piece mount that attaches to the 2020 extrusion frame and holds a silicone nozzle brush and a Sexball probe in line with the docking pathway.

**Nozzle brush:** The silicone brush cleans the nozzle automatically before a print, and before nozle offset calibration, preventing plastic buildup that could otherwise affect print quality or calibration accuracy.

**Sexball probe:** The the probe used to measure the nozzle position from multiple angles. XYZ offsets are then applied automatically across all six tool heads, eliminating the need for manual calibration. You can find details here: [Sexball BOM](https://github.com/DraftShift/StealthChanger/wiki/Bill-of-Materials#sexball-probe)
